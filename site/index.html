One approved script went into an n8n workflow and came out as this explainer and three vertical Shorts. Each hand-off waited for a sign-off before the next person could start. The device is fictional, invented for this demo.

Hand-offs, as they happened

Each ring is a waiting point in the workflow: the job stops there until someone answers. The role is the one the step is planned for. In this run every gate was answered by the builder, and the sheet says so.

    What actually ran

    Everything on this page came out of one run on one machine, with no call to a paid model API.

    Orchestration
    n8n 2.46, self-hosted with docker compose, on a network with no route out. It calls a small render service over HTTP; no Execute Command node.
    Voice
    Kokoro-82M run locally, British voice bf_emma, picked from four British voices.
    Image and motion
    Blender 5.2, one model of the lock built from code and lit like a clay study, rendered from a 16:9 and a 9:16 camera. The motion is the mechanism itself, not a video generator.
    Captions and labels
    Drawn from the voice's word timings, in Manrope.
    Sound
    The click and the section sweep are synthesised in code, timed to the lock. No music.
    Edit
    ffmpeg, loudness set to -16 LUFS.
    Paid tools
    None connected. The runbook names the one function each would replace: the voice line, the look frames, the scene clip.

    The repository replays the run from the same script: ./flow.py up, then ./flow.py run.
