DEMO-001

How a cartridge lock holds

Ready to upload

One approved script, a prepared shot plan and a 3D model went into an n8n workflow. This run produced a 72-second explainer and three vertical Shorts. A test refusal sent only Short 2 back. The device is fictional, invented for this demo.

Hand-offs, as they happened

Each ring is a waiting point in the workflow: the job stops there until someone answers. The role is the one the step is planned for. In this run the builder answered every gate from a script, a few seconds after each hand-off, and the refusal of Short 2 was staged: its caption was planned at the centre of the frame on purpose, to show a refusal going round. In a studio, each gate waits for a person.

    What actually ran

    Everything on this page came out of one machine, with no call to a paid model API. The Blender scenes were rendered once, in the first full run (about three hours). The run shown above started from an empty output folder: the voice lines, the storyboard sheet, the look frames and the scene renders came from the cache of earlier runs, and the master and the Shorts were cut again. Before it, line L10 of the script was rewritten and approved again; only that line was voiced again, and no scene went back to Blender.

    Orchestration
    n8n 2.46, self-hosted with docker compose, on a network with no route out. It calls a small render service over HTTP; no Execute Command node.
    Voice
    Kokoro-82M run locally, British voice bf_emma, kept from an audition of four British voices.
    Image and motion
    Blender 5.2, one model of the lock built from code and lit like a clay study, rendered from a 16:9 and a 9:16 camera. The motion is the mechanism itself, not a video generator.
    Captions and labels
    Drawn from the voice's word timings, in Manrope.
    Sound
    The click and the section sweep are synthesised in code. The click sounds at the lock and again, clear, in the pause after the word "click". No music.
    Edit
    ffmpeg, loudness set to -16 LUFS.
    Paid tools
    None connected. The runbook names the one function each would replace: the voice line, the look frames, the scene clip.

    The repository replays the run from the same script: ./flow.py up, then ./flow.py run --reject-short 2 --note "The caption covers the lug" --fix caption_pos=lower. Without --reject-short it approves every gate.
